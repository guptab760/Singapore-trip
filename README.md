# Singapore Family Trip Planner 2026

A GitHub Pages-ready static web app for the Singapore family trip (22–29 December 2026).

## Included
- ₹4.5 lakh trip budget
- ₹1.65 lakh flights and ₹2 lakh hotel preloaded as committed costs
- Day-by-day itinerary for 2 adults + 1 child (6 years)
- Add, delete and track actual expenses
- Expense categories and budget breakdown
- Automatic browser localStorage saving
- JSON export/import for backup or moving data to another device
- Mobile-friendly layout

## Publish on GitHub Pages
1. Create a new GitHub repository, e.g. `singapore-family-trip-2026`.
2. Upload `index.html`, `style.css`, `app.js`, and `README.md`.
3. In GitHub: **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`.
5. Save. GitHub will provide the Pages URL.

No backend is required. Expenses are stored locally in the browser. Use **Export Data** before switching devices or clearing browser storage.
